# SQL Practice

Practice queries for a BI / Data Analytics internship, written in T-SQL (SQL Server Express).

## Database
Two tables:
- customers (id, name, city)
- orders (id, customer_id, order_date, amount)

## Topics covered
- SELECT, WHERE, ORDER BY
- Aggregate functions (COUNT, SUM, AVG)
- Aliases
- JOINs (INNER, LEFT, RIGHT, FULL)
- GROUP BY and HAVING
- Logical execution order of a query

## How to run
1. Install SQL Server Express and SQL Server Management Studio (SSMS).
2. Create a database, for example `shop`.
3. Run section 00 (setup) of `sql_practice_day1.sql` once.
4. Run the other queries one by one.

## Files
- `sql_practice_day1.sql`: all practice queries with comments
